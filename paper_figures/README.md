# Paper figures — canonical set

**This folder is the single source of truth for paper figures.** Regenerate everything with:

```bash
.venv/bin/python paper_figures/make_paper_figures.py
```

All figures and `outlier_analysis.md` are produced from one file — `results/combined_6_grammar.csv`
(the 6-grammar oracle sweep, 1468 rows) — so numbers in the prose are guaranteed to match the plots.

## Conventions baked in
- **fig1 / fig2 show the uniform schedule only**, greedy vs categorical — the clean 2-line-per-panel
  comparison (matches `src/analyse.py`). Other schedules are qualitatively similar; the schedule
  comparison is made quantitatively in fig4 and per-cell in `x_figures/`.
- **Compute axis** = realised mean denoising steps (NFE); per-panel autoscaled (the two L regimes
  span different NFE ranges, so a shared axis would cramp the Dyck panels).
- **Degeneracy = collapse, not a T value.** A point is mode-collapsed when `uniqueness < 0.10`
  (≤10% distinct outputs); such points are *ringed* in fig1/fig2 so a high-accuracy single-string
  result is never read as skill. This can occur at T=1, 2 or 4 (e.g. bbaᴺ greedy at T=2).
- **"Who wins" comparisons use maximum compute**, where greedy is fully iterative and diverse —
  a degeneracy-free criterion (no T-threshold guessing).
- **Two length regimes** (not an error): single-string grammars swept at L=128, Dyck-2 at L=32.
- **Significance**: bands use `std_both_rules` over reps (n_reps=5 stochastic; greedy std≈0).
- **Diversity gate**: rows flagged `n_correct_too_low` (297/1468) have diversity set to NaN.
